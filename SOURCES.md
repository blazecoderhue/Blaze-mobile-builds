# Blaze Player: sources and their terms

Blaze Player ships **only** the sources below, pre-installed. It has no plugin, extension,
provider-repository or remote-install mechanism, and the agent API rejects any other host.

| # | Source | How it is reached | Terms / why it is licensed |
|---|---|---|---|
| a | **Your own files** (single files and a private "locker" folder) | Android Storage Access Framework only: `expo-document-picker` (ACTION_OPEN_DOCUMENT) for files and `Directory.pickDirectoryAsync` (ACTION_OPEN_DOCUMENT_TREE) for the locker. Read grants are made persistable. No storage permissions are requested (READ/WRITE/MANAGE_EXTERNAL_STORAGE and READ_MEDIA_* are blocked in the manifest). | The user picks content they hold. Nothing is uploaded or copied. |
| b | **Internet Archive: public-domain and Creative Commons feature films** | Official APIs only: `https://archive.org/advancedsearch.php` (search) and `https://archive.org/metadata/<identifier>` (item and file list), playing `https://archive.org/download/<identifier>/<file>.mp4`. Every query carries the filter `collection:(feature_films) AND mediatype:(movies) AND (licenseurl:*creativecommons.org* OR licenseurl:*publicdomain*) AND NOT licenseurl:*-nc*`. Before playing, the item's own metadata is checked again (it must be in `feature_films` and have a public-domain or CC licence without NonCommercial). | Each item carries the uploader's PD/CC declaration (`licenseurl`). Archive help: "The Internet Archive does not make guarantees as to the copyright status of items" (https://help.archive.org/help/rights). Terms of Use: https://archive.org/about/terms.php (the site's ToU says access to the Collections is "granted for scholarship and research purposes only", and licensed content may be used under its licence). NonCommercial CC items are excluded so that Blaze's distribution stays clear of NC terms. **Needs legal review before any commercial use.** The item page link (pageUrl) is kept for attribution. API docs: https://archive.org/developers/ |
| c | **Official free channels** | **None shipped.** There was no channel with a clearly official public API or feed that I could verify, so none was added. | Candidates, not included: NASA+ / NASA TV live streams (NASA media is generally not copyrighted, but no documented public stream API was confirmed); Library of Congress free films (official loc.gov JSON API, item-level rights vary); Wikimedia Commons video (official MediaWiki API, CC/PD per file); Blender Studio open movies (CC BY, already reachable through Internet Archive). |
| d | **Casting: Google Cast (Chromecast)** | `react-native-google-cast` 4.9.1, kept from Vega. Online (https) items only. Local `content://` files are not cast, because the receiver cannot read them and no local HTTP server is shipped. | react-native-google-cast is MIT. The Google Cast SDK is under the Google APIs Terms of Service. DLNA casting from Vega was removed with its local streaming server. |

Not a source, but on the network: archive.org thumbnails come from
`https://archive.org/services/img/<identifier>`. There are no other network endpoints
(no analytics, crash reporting, update checks or metadata services).
