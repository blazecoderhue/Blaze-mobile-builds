Blaze Player is a modified version of Vega (https://github.com/vega-org/vega-app) at commit
9ccc0c8 (9ccc0c8fc9f92702fd021f1b6f67e26e30988362), licensed under Apache-2.0. Modified by Blazeinchue.

As Apache License 2.0 Section 4(b) requires, this file lists every file that was changed relative to
upstream 9ccc0c8. Generated from `git diff --name-status 9ccc0c8`.

Summary of the modifications (2026-10):
* Removed: torrent/magnet streaming, every scraper/provider and the provider sandbox, the remote
  provider-repository / extension install mechanism, third-party metadata/scraping integrations,
  WebView/WAF/cookie tooling, DNS-over-HTTPS, the WARP and anti-DPI tunnels and their prebuilt
  binaries, the download manager, desktop sync, DLNA/remote delivery, the in-app APK updater, Firebase
  analytics/crashlytics, Vega's distribution files and the bundled debug.keystore.
* Added: licensed sources (your own files via SAF and a locker folder; Internet Archive public-domain/CC
  feature films), a play queue, Chromecast helpers, a signature-protected agent interface
  (com.blaze.player.permission.AGENT), new screens, tests and the Blaze rebrand (Blaze Player, com.blaze.player).
* Kept from Vega with minor or no changes: the media-console player chrome, theme, UI components and TV helpers.
